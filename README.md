# MYEbook_iphone

Prima versione della Web App per l'indice ebook.

La versione Android `my_ebook` non viene modificata.

Funzioni:
- indice locale tramite IndexedDB;
- link Dropbox memorizzato nel browser;
- ricerca autore/titolo;
- ordinamento per autore/titolo;
- selezione ebook;
- ricerca Google di autore o libro;
- CHECK manuale dell'indice remoto;
- download del nuovo indice solo dopo conferma.

Pubblicazione: GitHub Pages.
